# my-ticket-bedrock

Turn the **Light Block (Light 0)** into a custom ticket! Simply use an anvil to rename the item to **“Ticket”**, and it will transform into a ticket design.

The resource pack is available for **Minecraft Bedrock 26.45**!

This simple Minecraft Bedrock resource pack replaces the **`light_block_0`** texture with a custom ticket design featuring an orange color scheme and reflective details. It’s perfect for **servers, events, custom maps, and other creative projects**.

### Features

* Replaces the **Light Block (Light 0)** texture with a custom ticket design.
* Rename the item to **“Ticket”** using an anvil to activate the ticket texture.
* Orange ticket design with reflective details.
* Perfect for servers, events, custom maps, and more.
* Includes a **No Extra Modifications** version for a simple experience.
* The **Extra Modifications** version adds even more fun features, including a custom title logo and additional changes.

## Installation

1. Download the resource pack from the release page.
2. Open Minecraft Bedrock and go to **Settings → Global Resources**.
3. Find the downloaded resource pack and activate it.
4. If the pack is an `.mcpack` file, open it with Minecraft to install it automatically.
5. Once installed, activate the pack in your world or global resource settings.
6. Use an anvil to rename a **Light Block (Light 0)** to **“Ticket”** and enjoy your new ticket!
